# Purelane Shopify

Purelane is a plant-based homecare brand. This project is a Shopify storefront built using the Dawn theme and customized for the Purelane brand.

## What I built

- Custom homepage hero section
- Product / shop grid using Shopify products
- Best-selling combos section
- Product bundles section
- Customer reviews section
- Responsive layout for desktop and mobile
- Shopify product data, prices, images and inventory
- Editable sections through the Shopify theme editor

## Tech Used

- Shopify Liquid
- HTML
- CSS
- JavaScript
- Shopify Dawn theme

## Development

The theme was developed locally using Shopify CLI and then pushed to the Shopify development store.
